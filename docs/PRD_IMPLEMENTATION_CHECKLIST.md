# PRD实现执行检查清单

## 实现前检查

- [ ] 已完整阅读PRD文档
- [ ] 已提取所有功能点到对照表格
- [ ] 已识别P0/P1/P2优先级
- [ ] 已创建详细实现计划
- [ ] 已确认无理解歧义

## 实现过程检查

- [ ] 按优先级顺序实现（P0→P1→P2）
- [ ] 每实现一个功能点即时标记对照
- [ ] 每完成一个模块进行对照检查
- [ ] 遇到疑问立即确认不假设
- [ ] 保持代码风格一致

## 完成后检查

- [ ] P0功能100%实现
- [ ] P1功能全部实现或明确标记
- [ ] 功能对照表完整更新
- [ ] 每个功能点都有明确实现状态
- [ ] 完成度统计正确
- [ ] 生成最终总结报告

## 功能对照表格标准

必须包含以下列：
| 模块 | 功能点 | PRD要求 | Demo实现 | 优先级 | 备注 |

实现状态标记：
- ✅ = 已完全实现
- ⚠️ = 部分实现
- ❌ = 未实现
- N/A = 不适用
