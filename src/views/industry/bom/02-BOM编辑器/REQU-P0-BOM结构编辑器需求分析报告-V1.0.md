## 1. 文档概述

### 1.1 文档目的

本文档用于详细分析BOM结构编辑器模块的业务需求，为后续产品需求文档(PRD)、用例规约和技术设计提供输入依据。

### 1.2 产品定位

BOM结构编辑器是Ragentic Cube Suite平台的核心模块，用于管理产品的物料清单（BOM）结构，支持多种BOM视图、版本管理、结构对比等功能，与个人工作区、BOM数据发放紧密关联。

## 2. 用户角色分析

### 2.1 主要用户角色

| 角色 | 描述 | 核心诉求 |
|-----|------|---------|
| **BOM设计师** | 负责创建和维护BOM结构 | 快速编辑、版本管理、结构对比 |
| **项目经理** | 审核和发布BOM | 查看BOM结构、版本审批 |
| **工艺工程师** | 基于EBOM创建MBOM | BOM视图转换、结构适配 |
| **采购工程师** | 基于EBOM创建PBOM | 采购BOM管理 |

### 2.2 用户痛点

1. 多BOM视图切换繁琐，版本对比困难
2. BOM结构层级深，查找定位不方便
3. BOM变更影响分析不直观
4. 与个人工作区数据协同不顺畅

### 3.2 核心功能详细分析

#### 3.2.1 BOM视图管理

**功能描述：** 支持多种BOM视图，满足不同角色使用需求

**视图类型：**

| 视图 | 说明 | 典型用户 |
|-----|------|---------|
| EBOM | 工程BOM，反映设计意图 | 设计工程师 |
| MBOM | 制造BOM，用于生产制造 | 工艺工程师 |
| DBOM | 设计BOM，详细设计数据 | 设计师 |
| PBOM | 采购BOM，用于物料采购 | 采购工程师 |

**视图切换流程：**

```
视图切换流程：
┌──────────────┐
│ 选择BOM视图 │
└──────┬───────┘
       ▼
┌──────────────┐
│ 加载BOM结构  │
└──────┬───────┘
       ▼
┌──────────────┐
│ 渲染表格/树   │
└────────────┘
```

**业务规则：**

| 规则ID | 规则内容 | 优先级 |
|-------|---------|-------|
| FR-BV-001 | 视图切换不改变底层BOM结构 | P0 |
| FR-BV-002 | 不同视图可定义不同的默认列 | P1 |
| FR-BV-003 | 视图切换保留当前筛选条件 | P1 |

#### 3.2.2 显示模式

**功能描述：** 支持多种显示模式，便于查看不同粒度的BOM

| 显示模式 | 说明 | 使用场景 |
|---------|------|---------|
| 单层展开 | 仅显示直接子件 | 查看单层结构 |
| 多层展开 | 显示多层结构（可配置层级数） | 查看整体结构 |
| 最底层零件 | 仅显示叶节点 | 物料统计 |
| 汇总显示 | 数量汇总合并同名零件 | 采购/成本分析 |

**层级展开控制：**

| 功能 | 说明 | 优先级 |
|-----|------|-------|
| 全部展开 | 一键展开所有层级 | P0 |
| 全部折叠 | 一键折叠到根节点 | P0 |
| 按需加载 | 点击节点加载子件 | P0 |
| 展开到层级N | 最多展开到第N层 | P1 |

#### 3.2.3 BOM结构管理

**功能描述：** 对BOM结构进行增删改查操作

**节点操作：**

| 操作 | 快捷键 | 说明 | 优先级 |
|-----|-------|------|-------|
| 添加子件 | Tab/右键菜单 | 在当前节点下添加子零件 | P0 |
| 添加同级 | Enter/右键菜单 | 在当前节点同级添加 | P0 |
| 删除节点 | Delete | 删除节点及其子件 | P0 |
| 升级 | Alt+→ | 节点在同级中上移 | P0 |
| 降级 | Alt+← | 节点降为子件 | P0 |
| 上移 | Alt+↑ | 节点同级上移 | P0 |
| 下移 | Alt+↓ | 节点同级下移 | P0 |
| 剪切/复制/粘贴 | Ctrl+X/C/V | 节点复制移动 | P0 |

**层级约束：**

| 规则ID | 规则内容 | 优先级 |
|-------|---------|-------|
| FR-BS-001 | 最大层级深度：15层 | P0 |
| FR-BS-002 | 根节点唯一 | P0 |
| FR-BS-003 | 同级节点不允许重名 | P1 |
| FR-BS-004 | 循环引用检测，不允许自身引用 | P0 |

#### 3.2.4 BOM版本管理

**功能描述：** 管理BOM版本，支持版本创建、升版、发布、归档

**版本状态流转：**

```
                    ┌──────────┐
                    │ 设计中    │
                    └─────┬────┘
                          │
                          ▼
                    ┌──────────┐
                    │ 待发布    │◀─────┐
                    └─────┬────┘      │
                          │            │
                          ▼            │
                    ┌──────────┐      │
                    │ 已发布    │──────┘
                    └─────┬────┘
                          │
                          ▼
                    ┌──────────┐
                    │ 已归档    │
                    └──────────┘
```

**版本升版流程：**

```
升版流程：
┌──────────────┐
│ 点击"升版"  │
└──────┬───────┘
       ▼
┌──────────────┐
│ 选择升版类型 │
│ (主版本/次版本)│
└──────┬───────┘
       ▼
┌──────────────┐
│ 创建新版本   │
│ 复制原结构   │
└──────┬───────┘
       ▼
┌──────────────┐
│ 新版本状态:设计中│
└────────────┘
```

**业务规则：**

| 规则ID | 规则内容 | 优先级 |
|-------|---------|-------|
| FR-BV-001 | 新建BOM默认版本A.0 | P0 |
| FR-BV-002 | 升版复制完整结构 | P0 |
| FR-BV-003 | 历史版本只读 | P0 |
| FR-BV-004 | 发布后状态变更为"已发布" | P0 |
| FR-BV-005 | 归档版本不可修改 | P0 |

#### 3.2.5 BOM对比

**功能描述：** 对比两个版本的差异

**对比模式：**

| 对比类型 | 说明 | 优先级 |
|---------|------|-------|
| 版本对比 | 当前版本 vs 指定历史版本 | P0 |
| 基线对比 | 当前BOM vs 基线版本 | P1 |

**差异类型：**

| 差异类型 | 说明 | 颜色标识 |
|---------|------|---------|
| 新增 | 新增的节点 | 🟢 绿色 |
| 删除 | 删除的节点 | 🔴 红色 |
| 修改 | 属性变更的节点 | 🟠 橙色 |
| 移动 | 层级位置变更 | 🔵 蓝色 |

**差异统计：**

```
差异统计：
┌─────────────────────────────────┐
│ 总差异数：12                      │
│ ├── 🟢 新增：5                   │
│ ├── 🔴 删除：2                   │
│ ├── 🟠 修改：4                   │
│ └── 🔵 移动：1                   │
└─────────────────────────────────┘
```

#### 3.2.6 与零件版本关联

**功能描述：** BOM节点关联个人工作区中的零件版本

**关联关系：**

```
BOM节点 ←──────→ 零件版本
  │                │
  │  1:1引用       │  1:N版本
  │                │
  ▼                ▼
┌────────────────────────┐
│ BOM节点表             │
│ - node_id            │
│ - part_version_id    │────→ 零件版本表
│ - part_id            │      - version_id
└────────────────────────┘      - version_number
                                 - properties
```

**业务规则：**

| 规则ID | 规则内容 | 优先级 |
|-------|---------|-------|
| FR-BA-001 | 一个BOM节点关联一个零件版本 | P0 |
| FR-BA-002 | 零件版本升版后，BOM节点可选择性更新引用 | P0 |
| FR-BA-003 | BOM升版时，关联的零件版本引用保持不变 | P0 |

## 5. 数据流分析

### 5.1 与个人工作区的数据流

```
个人工作区                    BOM结构编辑器
┌─────────────┐            ┌─────────────┐
│ 零件主数据  │──────────▶│ BOM节点    │
│ Part       │  引用      │ BOMNode    │
└─────────────┘            └─────────────┘
      │                          │
      ▼                          ▼
┌─────────────┐            ┌─────────────┐
│ 零件版本   │            │ BOM版本    │
│ PartVersion│            │ BOMVersion │
└─────────────┘            └─────────────┘
```

### 5.2 BOM核心数据模型

| 字段 | 类型 | 说明 |
|-----|------|------|
| bom_id | VARCHAR(50) | BOM唯一标识 |
| bom_name | VARCHAR(200) | BOM名称 |
| bom_type | ENUM | BOM类型：EBOM/MBOM/DBOM/PBOM |
| root_part_id | VARCHAR(50) | 根节点零件ID |
| current_version | VARCHAR(20) | 当前版本号 |
| status | ENUM | 状态：设计中/待发布/已发布/已归档 |
