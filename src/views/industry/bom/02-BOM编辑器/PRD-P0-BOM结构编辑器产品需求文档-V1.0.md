## 1. 产品概述

### 1.1 产品定位

BOM结构编辑器是Ragentic Cube Suite平台的核心模块，为用户提供专业的BOM结构管理能力，支持多种BOM视图、版本管理、结构对比等核心功能，与个人工作区紧密集成。

### 1.2 核心价值

- **视图多样化**：支持EBOM/MBOM/DBOM/PBOM四种视图
- **操作高效**：支持快捷键、拖拽、批量操作
- **版本可控**：完整的版本管理，变更可追溯
- **对比直观**：差异高亮可视化

## 2. 用户场景

### 场景一：BOM结构编辑
> 设计工程师李工需要编辑产品BOM结构。

**用户流程：**
1. 打开BOM结构编辑器
2. 选择BOM视图（EBOM）
3. 选中目标节点
4. 使用Tab键添加子件
5. 输入/选择零件
6. 保存结构

### 场景二：BOM版本对比
> 项目经理王工需要对比两个版本的差异。

**用户流程：**
1. 选择BOM结构
2. 点击"版本对比"
3. 选择对比版本（当前版本 vs A.1）
4. 系统显示差异对比视图
5. 查看新增/修改/删除节点
6. 导出差异报告

### 4.2 BOM结构树

**功能：** 左侧树形展示BOM层级结构

**布局：**

```
┌──────────────────────────────────┐
│ 🔍 搜索节点...                    │
├──────────────────────────────────┤
│ 📦 总成_A           A.2          │ ← 根节点
│ ├─ 📦 部件_A1       B.1     ×2   │
│ │  ├─ 🔩 零件_A11   A.0     ×4   │
│ │  └─ 🔩 零件_A12   A.1     ×2   │
│ ├─ 📦 部件_A2       A.0     ×1   │
│ │  ├─ 🔩 零件_A21   A.0     ×1   │
│ │  └─ 🔩 零件_A22   A.0     ×1   │
│ └─ 🔩 标准件_A3     A.0     ×8   │
└──────────────────────────────────┘
```

**交互：**

| 交互 | 行为 |
|-----|------|
| 单击节点 | 选中节点，同步选中表格行 |
| 双击节点 | 展开/折叠子节点 |
| 右键节点 | 弹出操作菜单 |

**节点右键菜单：**

```
┌─────────────────┐
│ ➕ 添加子件      │

├─────────────────┤
```

## 5. 交互设计

### 5.1 快捷键

| 快捷键 | 功能 |
|-------|------|
| Tab | 添加子件 |
| Enter | 添加同级 |
| Delete | 删除节点 |
| Alt+→ | 升级 |
| Alt+← | 降级 |
| Alt+↑ | 上移 |
| Alt+↓ | 下移 |
| Ctrl+C | 复制 |
| Ctrl+V | 粘贴 |
| Ctrl+Z | 撤销 |
| Ctrl+Y | 重做 |
| Ctrl+S | 保存 |
| F2 | 重命名 |
| Ctrl+F | 搜索节点 |

### 5.2 拖拽操作

| 拖拽方向 | 功能 |
|---------|------|
| 拖拽到子节点区域 | 成为子件（降级） |
| 拖拽到同级区域 | 移动位置 |
| 拖拽到其他节点 | 成为该节点的子件 |

## 6. 错误处理

### 6.1 错误提示

| 场景 | 提示 |
|-----|------|
| 循环引用 | "操作会导致循环引用，请重新选择" |
| 最大层级超限 | "已达到最大层级15层" |
| 同级重名 | "该位置已存在同名零件" |
| 版本已发布 | "已发布版本不可修改，请先创建新版本" |
