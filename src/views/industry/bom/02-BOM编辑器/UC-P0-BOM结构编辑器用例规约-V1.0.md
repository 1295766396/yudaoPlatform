## 2. 详细用例

### UC-BE-001 切换BOM视图

| 字段 | 内容 |
|-----|------|
| **用例编号** | UC-BE-001 |
| **用例名称** | 切换BOM视图 |
| **参与者** | BOM设计师、项目经理 |
| **前置条件** | BOM存在 |
| **后置条件** | 视图切换成功，显示对应数据 |
| **基本流程** | 1. 用户点击视图选择器<br/>2. 选择目标视图（EBOM/MBOM/DBOM/PBOM）<br/>3. 系统加载该视图数据<br/>4. 系统刷新表格/树显示 |
| **备选流程** | 2a. 选择当前视图<br/>  &nbsp;&nbsp;&nbsp;&nbsp;→ 不刷新，直接返回 |
| **异常处理** | 视图数据加载失败：提示"加载失败，请重试" |
| **验收标准** | ✅ 视图正确切换<br/>✅ 数据完整显示 |

### UC-BE-002 添加子件节点

| 字段 | 内容 |
|-----|------|
| **用例编号** | UC-BE-002 |
| **用例名称** | 添加子件节点 |
| **参与者** | BOM设计师 |
| **前置条件** | BOM存在，且选中节点 |
| **后置条件** | 新节点创建成功 |
| **基本流程** | 1. 用户选中目标节点<br/>2. 按Tab键或右键选择"添加子件"<br/>3. 系统在选中节点下插入新行<br/>4. 用户输入/搜索零件<br/>5. 用户确认选择<br/>6. 系统创建BOM节点并关联零件版本 |
| **备选流程** | 2a. 用户点击工具栏"添加子件"<br/>  &nbsp;&nbsp;&nbsp;&nbsp;→ 系统使用当前选中节点<br/>4a. 零件不存在<br/>  &nbsp;&nbsp;&nbsp;&nbsp;→ 提示"零件不存在，是否新建？"<br/>4b. 搜索零件<br/>  &nbsp;&nbsp;&nbsp;&nbsp;→ 显示搜索结果列表 |
| **异常处理** | 层级超限（15层）：提示"已达最大层级限制"<br/>循环引用检测：提示"不允许循环引用" |
| **验收标准** | ✅ 节点创建成功<br/>✅ 节点位于正确层级<br/>✅ 节点关联零件版本 |

### UC-BE-005 节点升级/降级

| 字段 | 内容 |
|-----|------|
| **用例编号** | UC-BE-005 |
| **用例名称** | 节点升级/降级 |
| **参与者** | BOM设计师 |
| **前置条件** | BOM存在，且选中节点 |
| **后置条件** | 节点层级变更 |
| **基本流程（升级）** | 1. 用户选中节点<br/>2. 按Alt+→键或右键选择"升级"<br/>3. 系统将节点移动到父节点同级<br/>4. 原位置后续节点上移补位<br/>5. 系统刷新表格 |
| **基本流程（降级）** | 1. 用户选中节点<br/>2. 按Alt+←键或右键选择"降级"<br/>3. 系统将节点移动到前一个同级节点下<br/>4. 系统刷新表格 |
| **备选流程** | 升级：<br/>4a. 节点是父节点第一个子节点<br/>  &nbsp;&nbsp;&nbsp;&nbsp;→ 提示"无法升级到更高级"<br/>降级：<br/>4a. 节点是同级第一个<br/>  &nbsp;&nbsp;&nbsp;&nbsp;→ 提示"无法降级" |
| **异常处理** | 升级后层级超限：提示"已达最大层级" |
| **验收标准** | ✅ 节点层级正确变更<br/>✅ 表格显示正确 |
