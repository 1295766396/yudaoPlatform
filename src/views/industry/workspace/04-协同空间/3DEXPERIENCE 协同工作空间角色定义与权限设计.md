# 3DEXPERIENCE 协同工作空间角色定义与权限设计

## 一、核心角色定义

3DEXPERIENCE 协同工作空间基于**基线角色（Baseline Roles）** 实现权限分层，角色权限逐级继承，分为**应用角色**（业务用户）与**管理角色**（管理员 / 运维）两大类，共 7 个标准角色。

### 1\. 应用角色（业务用户）

|角色|权限继承|核心能力|数据操作边界|
|---|---|---|---|
|**公共读者（Public Reader）**|无|仅访问协作空间内**公开内容**|只读；无创建 / 修改 / 删除|
|**读者（Reader）**|继承公共读者|访问所属组织 / 协作空间**全部内容**|只读；可创建个人收藏夹 / 文件夹（私有）|
|**贡献者（Contributor）**|继承读者|可创建**评估类内容**|可创建评审、仿真等非正式业务数据|
|**作者（Author）**|继承贡献者|可创建**正式业务对象**|可创建需求、零件、EBOM、系统模型等|
|**领导者（Leader）**|继承作者|可管理**公共资源**|可创建设计资源库、项目模板、公共文件夹|

### 2\. 管理角色（运维 / 管理员）

|角色|权限范围|核心管理能力|
|---|---|---|
|**所有者（Owner）**|单个协作空间|管理空间成员、配置资源、修改内容属性（异常场景）、查看私有数据|
|**管理员（Administrator）**|全平台所有空间|全平台用户 / 组织 / 协作空间统一管理，最高权限，跨空间运维|

## 二、权限设计核心框架

### 1\. 权限分类（双权限体系）

1. **数据权限**

    - 控制数据访问范围与操作（读 / 写 / 删）

    - 与许可证无关，不产生额外成本

    - 基于组织、协作空间、生命周期状态判定

2. **应用权限**

    - 控制可使用的平台功能 / APP（如装配设计、流程管理）

    - 与许可证直接绑定，决定用户可用功能集

    - 以 “角色” 为单位授权

### 2\. 安全上下文（核心权限机制）

- 定义：用户工作环境 = **组织 \+ 基线角色 \+ 协作空间**

- 规则：

    1. 一个用户可分配多个安全上下文

    2. **读取**：继承所有上下文权限

    3. **写入 / 创建**：仅当前**活动上下文**生效

    4. 数据归属：创建内容绑定当前活动上下文

### 3\. 协作空间可见度权限（4 种类型）

|可见度类型|访问规则|适用场景|
|---|---|---|
|**公开（Public）**|同组织 / 上级组织可见，私密内容除外|通用共享数据|
|**受保护（Protected）**|仅已发布 / 过期内容对同组织可见|受控共享数据|
|**私密（Private）**|仅空间成员可见|核心涉密 / 内部数据|
|**标准（Standard）**|权限同私密，用于标准件管理|标准资源库|

### 4\. 内容访问判定规则

- 最终权限 = **协作空间可见度 \+ 内容生命周期状态**

- 生命周期状态：在制品 → 冻结 → 已发布 → 废弃

- 私密状态内容：**仅创建者本人可见**

### 5\. 批量授权机制

- 支持**用户组**授权：安全上下文分配给组，组内用户自动继承

- 支持多组叠加权限，简化批量管理

## 三、权限边界总表

|角色|核心权限|数据范围|关键操作|
|---|---|---|---|
|公共读者|只读公开内容|本空间公开数据|仅查看|
|读者|只读全部|本组织 / 空间|查看 \+ 创建个人内容|
|贡献者|可创建评估内容|本组织 / 空间|\+ 创建评审 / 仿真|
|作者|可创建正式数据|本组织 / 空间|\+ 创建设计 / BOM / 需求|
|领导者|管理公共资源|本空间|\+ 管理资源库 / 模板|
|所有者|空间管理员|本空间|\+ 管理成员 / 修改属性|
|管理员|平台超级管理员|全平台|\+ 全平台用户 / 组织 / 配置|

---

## 四、权限校验流程

1. 身份认证：3DPassport（SSO）验证身份

2. 安全上下文：选定当前活动组织 \+ 角色 \+ 协作空间

3. 权限校验：

    - 是否为平台管理员？

    - 用户 / 组 / 角色是否被授权？

    - 生命周期状态是否允许操作？

    - 是否有规则禁止操作？

4. 执行结果：允许 / 拒绝

---

## 五、配置与部署要点

1. **协作空间控制中心**

    - 新建 / 编辑协作空间、设置可见度、转移所有权

    - 管理空间成员与角色分配

2. **协作空间配置中心**

    - 定义命名规则、修订规则、生命周期策略

    - 配置属性扩展、访问规则、成熟度图

3. **部署工具**

    - 支持配置导入 / 导出、缓存重载、索引更新

    - 新属性批量同步至历史对象
