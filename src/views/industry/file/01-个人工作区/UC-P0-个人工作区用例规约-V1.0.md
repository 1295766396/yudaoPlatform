## 2. 文件夹管理用例

### UC-PW-001 创建文件夹

| 字段 | 内容 |
|-----|------|
| **用例编号** | UC-PW-001 |
| **用例名称** | 创建文件夹 |
| **参与者** | 个人设计师 |
| **前置条件** | 用户已登录个人工作区 |
| **后置条件** | 新文件夹创建成功，显示在文件夹树中 |
| **基本流程** | 1. 用户在文件列表中点击"新建"按钮<br/>2. 选择"新建文件夹"<br/>3. 系统显示文件夹名称输入框<br/>4. 用户输入文件夹名称<br/>5. 用户点击"确定"<br/>6. 系统创建文件夹并刷新列表 |
| **备选流程** | 4a. 用户不输入名称直接点击确定<br/>  &nbsp;&nbsp;&nbsp;&nbsp;→ 系统提示"请输入文件夹名称"<br/>4b. 用户输入已存在的名称<br/>  &nbsp;&nbsp;&nbsp;&nbsp;→ 系统提示"该文件夹已存在" |
| **异常处理** | 网络断开：提示"网络异常，请检查网络连接"<br/>权限不足：提示"您没有在该位置创建文件夹的权限" |
| **验收标准** | ✅ 文件夹创建成功<br/>✅ 文件夹显示在正确的位置<br/>✅ 文件夹名称符合命名规范 |
