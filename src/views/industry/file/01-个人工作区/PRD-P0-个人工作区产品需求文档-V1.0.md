## 1. 文档概述

### 1.1 产品概述

个人工作区是Ragentic Cube Suite平台的核心模块，为用户提供基于Home文件夹的个人数据管理空间。系统以**内容关系**为核心模型组织数据，支持文件夹、文档、零件、数据集等多种业务对象的统一管理。个人工作区与BOM结构编辑器紧密关联，为产品协同设计提供基础数据支撑。

### 1.2 产品定位

- **核心价值**：为用户提供安全、高效的个人数据管理空间
- **使用场景**：个人设计师日常文件管理、项目数据组织
- **目标用户**：个人设计师、研发工程师、项目团队成员

### 1.3 核心概念

| 概念 | 说明 |
|-----|------|
| **Home文件夹** | 用户登录后默认的根目录，基于此创建和管理所有内容，不可删除和重命名 |
| **WorkspaceObject** | 工作区对象，包括：文件夹、文档、零件、版本、数据集（文件不在左侧树中显示） |
| **内容关系** | 文件夹、文档、零件、数据集之间的组织关系，支持拖拽排序和展开/收缩 |
| **业务对象** | 文档（SOR/BRD/PRD/Report等）、零件（装配/零件）、数据集（PPT/Excel/Word/PDF/CATProduct/CATPart/ZIP等），类型可动态配置 |
| **版本对象** | 文档和零件支持多版本管理，版本下可关联数据集 |

### 1.4 设计原则

| 原则 | 说明 |
|-----|------|
| 直观易用 | 延续Windows资源管理器操作习惯 |
| 高效响应 | 所有操作响应时间≤2s |
| 安全可靠 | 数据隔离、操作可追溯 |
| 协作便捷 | 支持快速分享与协作 |

## 2. 用户与场景

### 2.1 目标用户

| 用户角色 | 描述 | 核心诉求 |
|---------|------|---------|
| 个人设计师 | 负责具体零件设计的工程师 | 快速创建业务对象、版本管理、与BOM关联 |
| 项目参与者 | 参与项目协同的团队成员 | 查看项目文件、数据同步 |
| 项目管理员 | 负责项目空间管理 | 权限分配、数据整理 |

### 2.2 典型用户场景

#### 场景一：设计师日常文件管理
> 李工是汽车零部件设计师，每天需要在个人工作区中管理大量CATIA文件和文档。

**用户流程：**
1. 李工登录系统，进入个人工作区
2. 在左侧内容关系树中看到Home文件夹
3. 右键Home文件夹，选择"新建零件" → "装配"
4. 输入零件信息"总成A"
5. 系统创建零件并显示在Home下
6. 李工在零件上右键，选择"添加数据集"
7. 上传CATIA文件到数据集

#### 场景二：文档版本管理
> 王工需要管理设计文档的多版本。

**用户流程：**
1. 王工在Home下右键，选择"新建文档" → "PRD"
2. 创建"产品规格说明书"文档
3. 首次创建时自动生成版本A.0
4. 王工编辑文档后，右键版本"A.0"，选择"升版"
5. 系统创建新版本A.1
6. 点击文档节点，右侧显示版本列表

#### 场景三：内容拖拽排序
> 张工需要调整文件顺序来组织项目结构。

**用户流程：**
1. 在内容关系树中选中多个对象
2. 拖拽选中的对象
3. 移动到目标位置
4. 释放鼠标，对象移动到新位置
5. 顺序改变

#### 场景四：查看对象属性与附件
> 赵工需要查看零件的详细信息和关联文件。

**用户流程：**
1. 在内容关系树中点击零件"支架_A"
2. 右侧属性面板显示概览信息（编号、类型、材料等）
3. 下半部分显示版本列表
4. 点击"附件"Tab
5. 显示按数据集分组的所有文件
6. 支持文件下载

#### 场景五：版本下添加数据集
> 李工完成了零件版本的设计，需要上传CATIA文件。

**用户流程：**
1. 在内容关系树中找到零件版本"A.1"
2. 右键版本，选择"添加数据集"
3. 输入数据集名称"原始数据"
4. 系统创建数据集并关联到该版本
5. 上传CATPart文件到数据集

**按钮说明：**

| 按钮 | 说明 | 状态 |
|-----|------|------|
| 新建文件夹 | 创建一个新的文件夹 | 始终可用 |
| 新建文档▼ | 二级菜单：SOR/BRD/PRD/Report | 始终可用 |
| 新建零件▼ | 二级菜单：装配/零件 | 始终可用 |
| 新建数据集▼ | 二级菜单：PPT/Excel/Word/PDF/CATProduct/CATPart/ZIP | 始终可用 |

| 刷新 | 刷新内容关系树 | 始终可用 |

**二级菜单配置说明：**
- 文档类型：SOR、BRD、PRD、Report等，可根据模型动态配置
- 零件类型：装配、零件等，可根据模型动态配置
- 数据集类型：PPT、Excel、Word、PDF、CATProduct、CATPart、ZIP等，可根据模型动态配置

### 4.2 左侧内容关系树

#### 4.2.1 Home文件夹

**布局：**

```
┌─────────────────────────────────────────────┐
│ 🏠 Home                                    │
│     /Home                                  │
└─────────────────────────────────────────────┘
```

**说明：**
- Home是系统默认的根文件夹，用户登录后自动创建
- Home下可以创建文件夹、文档、零件、数据集
- Home不可删除、不可重命名

#### 4.2.2 树节点类型

**文件夹节点：**
```
├─ 📁 项目A
│   ├─ 📁 总成零件
│   └─ 📁 参考文档
```

**文档节点（含版本标记）：**
```
├─ 📄 设计说明书
│   [B.0]
```

**零件节点（含版本标记）：**
```
├─ 🔧 支架_A
│   [A.1]
```

**版本节点：**
```
│   ├─ 📄 B.1 ← 当前
│   │   [已发布]
│   └─ 📄 B.0
│       [设计中]
```

**数据集节点（文件不在左侧显示）：**
```
│   ├─ 📎 原始数据 (2个文件)
│   └─ 📎 参考文档 (1个文件)
```

> **说明**：数据集下的文件不在左侧树中显示，选择数据集后，文件列表在右侧属性面板的内容列表中展示。

**展开/收缩规则（三级对象交互逻辑）：**

| 节点类型 | 点击行为 | 是否自动展开 | 右侧内容列表 |
|---------|---------|------------|-------------|
| 文件夹 | **展开/收缩子内容**（文件夹、文档、零件） | 用户控制 | 显示子对象列表 |
| 文档 | **展开版本列表** | **不自动展开** | 显示版本列表 |
| 零件 | **展开版本列表** | **不自动展开** | 显示版本列表 |
| 版本 | **展开数据集列表** | 用户控制 | 显示数据集列表 |
| 数据集 | **不展开文件**（文件在右侧查看） | 不展开 | 显示文件列表 |

**三级对象交互逻辑说明：**

1. **第一级：文件夹及内容**
   - 基于文件夹展开，支持全部展开或收缩
   - 文件夹下包含：子文件夹、文档、零件
   - 点击文件夹箭头展开/收缩所有子内容

2. **第二级：文档/零件 → 版本**
   - 基于文档或零件的**单击**完成版本展开
   - 文档/零件节点不自动展开版本，需手动点击
   - 展开后右侧内容列表显示版本列表

3. **第三级：版本 → 数据集**
   - 基于版本的**单击**操作数据集展开
   - 版本展开后右侧内容列表显示数据集列表

4. **数据集 → 文件**
   - 点击数据集**不展开文件**
   - 文件仅在右侧属性面板的内容列表中显示
   - 文件支持下载操作

**左侧树对象范围：**
- ✅ **WorkspaceObject**：文件夹、文档、零件、版本、数据集
- ❌ **非WorkspaceObject**：文件（不在左侧树中显示）

#### 4.2.3 拖拽排序

**拖拽规则：**
- 同一层级内可拖拽改变顺序
- 支持跨文件夹拖拽移动
- 拖拽时显示放置目标位置
- 释放后更新顺序/位置

**视觉效果：**
- 拖拽中：节点半透明
- 放置目标：目标节点高亮

### 4.5 业务对象创建流程

#### 4.5.1 创建文档

```
用户操作：右键 → 新建文档 → 选择类型(SOR/BRD/PRD/Report)
    ↓
系统行为：
1. 弹出创建对话框
2. 用户输入文档名称
3. 系统创建文档对象
4. 自动创建初始版本A.0
5. 在Home/当前文件夹下显示新文档节点
6. 文档节点显示最新版本标记
```

#### 4.5.2 创建零件

```
用户操作：右键 → 新建零件 → 选择类型(装配/零件)
    ↓
系统行为：
1. 弹出创建对话框
2. 用户输入零件信息（名称、编号、类型等）
3. 系统创建零件对象
4. 自动创建初始版本A.0
5. 在Home/当前文件夹下显示新零件节点
6. 零件节点显示最新版本标记
```

#### 4.5.3 创建数据集

**方式一：独立创建（不关联版本）**
```
用户操作：右键 → 新建数据集 → 选择类型
    ↓
系统行为：
1. 弹出创建对话框
2. 用户输入数据集名称
3. 选择类型（CATPart/Word/PDF等）
4. 系统创建独立数据集
5. 可后续关联到任意版本
```

**方式二：基于版本创建**
```
用户操作：右键版本 → 添加数据集
    ↓
系统行为：
1. 弹出创建对话框
2. 用户输入数据集名称
3. 选择类型
4. 系统创建数据集并关联到该版本
5. 版本下显示新数据集节点
```
