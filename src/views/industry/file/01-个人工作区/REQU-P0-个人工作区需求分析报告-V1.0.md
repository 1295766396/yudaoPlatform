## 1. 文档概述

### 1.1 文档目的

本文档用于详细分析个人工作区模块的业务需求，为后续产品需求文档(PRD)、用例规约和技术设计提供输入依据。

### 1.2 适用范围

- 适用版本：Ragentic Cube Suite 阶段1 (MVP)
- 适用用户：个人设计师、研发工程师、项目团队成员
- 使用场景：个人数据管理、文件组织、版本管理

### 1.3 参考文档

| 文档名称 | 版本 | 编制人 |
|---------|------|-------|
| CUBE-PROJECT-P0-阶段1-MVP设计输入文档 | V1.0 | AITC |

### 1.4 核心概念定义

| 概念 | 定义 | 说明 |
|-----|------|------|
| **Home文件夹** | 用户登录后自动创建的根目录 | 每个用户有独立的Home，不可删除/重命名 |
| **WorkspaceObject** | 工作区管理的核心对象 | 包括：文件夹、文档、零件、版本、数据集（文件不在左侧树中显示） |
| **内容关系** | 文件夹、文档、零件、数据集之间的组织关系 | 支持拖拽改变位置和顺序 |
| **业务对象** | 文档、零件、数据集等可管理的实体 | 可根据模型动态配置类型 |
| **版本对象** | 文档和零件的多版本数据 | 版本下可关联数据集 |
| **数据集** | 存储具体文件的容器 | 可关联版本，也可独立存在，文件在右侧属性面板查看 |

## 2. 用户角色分析

### 2.1 主要用户角色

| 角色 | 描述 | 使用频率 | 核心诉求 |
|-----|------|---------|---------|
| **个人设计师** | 负责具体零件/文档设计的工程师 | 高 | 快速创建、版本管理、文件组织 |
| **项目参与者** | 参与项目协同的团队成员 | 中 | 查看他人分享的文件、数据同步 |
| **项目管理员** | 负责项目空间管理的角色 | 低 | 空间权限分配、数据整理 |

### 2.2 用户特征分析

#### 个人设计师特征
- **工作习惯**：习惯使用Windows资源管理器组织文件
- **技术背景**：熟悉CATIA等CAD软件
- **效率诉求**：希望操作直观、响应快速
- **协作需求**：偶尔需要分享文件给团队成员

#### 用户痛点
1. 文件分散在多个目录，难以统一管理
2. 版本管理混乱，不知道哪个是最新版本
3. 文件与BOM关联不直观
4. 批量操作不方便

## 3. 功能需求分析

### 3.1 功能总览

```
个人工作区
├── Home文件夹
│   ├── 默认根目录（用户登录后自动创建）
│   └── 基于Home创建所有内容
├── 内容关系树（仅显示WorkspaceObject）
│   ├── 文件夹（支持展开/收缩子内容）
│   ├── 文档节点（点击展开版本）
│   │   └── 版本（右键添加数据集，点击展开数据集）
│   │       └── 数据集（文件不在左侧显示，在右侧查看）
│   └── 零件节点（点击展开版本）
│       └── 版本（右键添加数据集，点击展开数据集）
│           └── 数据集（文件不在左侧显示，在右侧查看）
├── 右键菜单
│   ├── 新建文件夹
│   ├── 新建文档（二级菜单：SOR/BRD/PRD/Report等）
│   ├── 新建零件（二级菜单：装配/零件等）
│   ├── 新建数据集（二级菜单：PPT/Excel/Word/PDF等）
│   ├── 添加数据集（仅版本对象）
│   ├── 升版（仅版本对象）
│   ├── 重命名/复制/剪切/粘贴
│   └── 删除/属性
├── 拖拽排序
│   ├── 同级内拖拽改变顺序
│   └── 跨文件夹拖拽移动
├── 三级对象交互逻辑
│   ├── 一级：文件夹及内容展开（支持全部展开/收缩）
│   ├── 二级：文档/零件单击展开版本
│   └── 三级：版本单击展开数据集
├── 属性面板（上下结构）
│   ├── 概览信息（对象属性）
│   └── 内容列表（子对象列表，数据集时显示文件列表）
└── 多Tab面板
    ├── 属性（上下结构）
    ├── 预览
    ├── 附件（数据集分组文件列表）
    ├── 影响分析
    ├── 流程状态
    └── 审计日志
```

### 3.2 展开逻辑规则

| 节点类型 | 点击行为 | 是否自动展开 | 说明 |
|---------|---------|------------|------|
| Home文件夹 | 显示内容 | 是 | 用户入口 |
| 文件夹 | 展开/收缩子节点 | 用户控制 | 支持多级嵌套 |
| 文档 | **展开版本列表** | **否** | 需手动点击 |
| 零件 | **展开版本列表** | **否** | 需手动点击 |
| 版本 | 展开数据集列表 | 用户控制 | 右键支持添加数据集 |
| 数据集 | 展开文件列表 | 用户控制 | 支持上传/下载文件 |

### 3.3 核心功能详细分析

#### 3.3.1 Home文件夹

**功能描述：** 用户登录后自动创建的根目录，是所有内容的起点

**Home文件夹特性：**

| 特性 | 说明 |
|-----|------|
| 自动创建 | 用户首次登录时自动创建Home文件夹 |
| 唯一性 | 每个用户有且只有一个Home文件夹 |
| 不可删除 | Home文件夹不可被删除 |
| 不可重命名 | Home文件夹名称固定为"Home" |
| 路径固定 | 路径固定为 `/Home` |

**Home文件夹下可创建的内容：**

| 内容类型 | 说明 |
|---------|------|
| 文件夹 | 自定义文件夹，用于组织内容 |
| 文档 | SOR/BRD/PRD/Report等，根据模型配置 |
| 零件 | 装配/零件等，根据模型配置 |
| 数据集 | 独立数据集，不关联任何版本 |

#### 3.3.2 文件夹管理

**功能描述：** 以树形结构组织和管理内容，支持多层级嵌套

**用户场景：**
1. 用户A需要在Home下创建一个"项目A"文件夹
2. 在"项目A"下创建"总成零件"和"参考文档"子文件夹
3. 将相关零件移动到"总成零件"文件夹中

**功能流程：**

```
创建文件夹流程：
┌─────────┐
│ 右键菜单 │
└────┬────┘
     ▼
┌─────────┐
│ 选择"新建文件夹"│
└────┬────┘
     ▼
┌─────────────────┐
│ 输入文件夹名称   │
└────┬────────────┘
     ▼
┌─────────┐
│ 确认创建│
└────┬────┘
     ▼
┌─────────┐
│ 显示成功│
└─────────┘
```

**业务规则：**
| 规则ID | 规则内容 | 优先级 |
|-------|---------|-------|
| FR-FL-001 | 文件夹名称不能超过100个字符 | P0 |
| FR-FL-002 | 文件夹名称不能包含特殊字符：`\ / : * ? " < > |` | P0 |
| FR-FL-003 | 同一目录下不能有同名文件夹 | P0 |
| FR-FL-004 | 文件夹层级深度不能超过10层 | P1 |
| FR-FL-005 | 文件夹支持重命名，名称变更后自动更新引用 | P0 |

**性能要求：**
- 文件夹创建响应时间 ≤ 500ms
- 文件夹列表加载时间 ≤ 1s（1000个文件夹以内）
- 文件夹移动/重命名响应时间 ≤ 1s

#### 3.2.2 零件管理

**功能描述：** 管理零件主数据及其版本，支持与BOM结构关联

**数据模型：**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| part_id | VARCHAR(50) | 是 | 零件唯一标识 |
| part_number | VARCHAR(100) | 是 | 零件号 |
| part_name | VARCHAR(200) | 是 | 零件名称 |
| part_type | ENUM | 是 | 零件类型：自制件/外购件/标准件/虚拟件 |
| material | VARCHAR(100) | 否 | 材料 |
| weight | DECIMAL(10,3) | 否 | 重量(kg) |
| version | VARCHAR(20) | 是 | 当前版本号 |
| status | ENUM | 是 | 状态：设计中/已发布/已归档 |
| owner_id | VARCHAR(50) | 是 | 所有者ID |
| created_by | VARCHAR(50) | 是 | 创建人 |
| created_time | DATETIME | 是 | 创建时间 |
| updated_by | VARCHAR(50) | 是 | 最后修改人 |
| updated_time | DATETIME | 是 | 最后修改时间 |

**版本管理规则：**
| 规则ID | 规则内容 | 优先级 |
|-------|---------|-------|
| FR-PR-001 | 零件版本号格式：主版本.次版本（如A.0、A.1、B.0） | P0 |
| FR-PR-002 | 新建零件默认版本为A.0 | P0 |
| FR-PR-003 | 版本升序规则：主版本升序 > 次版本归零 > 次版本升序 | P0 |
| FR-PR-004 | 版本升版后自动创建新版本记录 | P0 |
| FR-PR-005 | 历史版本不可修改，只能查看 | P0 |

**功能流程：**

```
零件版本升版流程：
┌──────────────┐
│ 选择零件     │
└──────┬───────┘
       ▼
┌──────────────┐
│ 点击"升版"   │
└──────┬───────┘
       ▼
┌──────────────────┐
│ 系统自动分配新版本号│
└──────┬───────────┘
       ▼
┌──────────────┐
│ 生成新版本   │
└──────┬───────┘
       ▼
┌──────────────┐
│ 状态变更为"设计中"│
└──────┬───────┘
       ▼
┌──────────────┐
│ 版本历史记录+1│
└──────────────┘
```

#### 3.2.4 文件管理

**功能描述：** 管理零件、文档关联的文件，支持大文件分片上传

**核心功能：**

| 功能 | 描述 | 优先级 |
|-----|------|-------|
| 文件上传 | 支持拖拽上传、批量上传 | P0 |
| 大文件分片上传 | 支持>100MB文件分片上传 | P0 |
| 断点续传 | 网络中断后支持续传 | P0 |
| 文件下载 | 支持单个/批量下载 | P0 |
| 文件预览 | 支持图片/PDF/Office在线预览 | P1 |
| 文件哈希校验 | MD5/SHA256校验保证完整性 | P0 |

**文件存储规则：**
| 规则ID | 规则内容 | 优先级 |
|-------|---------|-------|
| FR-FI-001 | 单个文件大小限制：2GB | P0 |
| FR-FI-002 | 文件存储路径：`/storage/files/{user_id}/{date}/{file_id}/{file_name}` | P0 |
| FR-FI-003 | 文件必须与零件版本或文档版本关联 | P0 |
| FR-FI-004 | 上传文件自动计算MD5值 | P0 |
| FR-FI-005 | 相同文件哈希值不重复存储 | P1 |

       ▼
┌──────────────┐

└──────┬───────┘
       ▼

       ▼

#### 3.2.5 数据集管理

**功能描述：** 数据集是零件或文档的附件集合，支持独立创建、基于版本创建、文件管理

**核心功能：**

| 功能 | 描述 | 优先级 |
|-----|------|-------|
| 独立创建数据集 | 在文件夹下直接创建空数据集 | P0 |
| 基于零件版本创建 | 选择零件及版本，创建关联的数据集 | P0 |
| 基于文档版本创建 | 选择文档及版本，创建关联的数据集 | P0 |
| 立即上传文件 | 创建数据集时同时上传文件 | P0 |
| 数据集内文件管理 | 添加/删除/重命名/预览数据集内文件 | P0 |
| 数据集属性编辑 | 编辑数据集名称、描述 | P1 |

**典型用户场景：**

**场景一：独立创建数据集**
> 设计师需要创建一个空白的数据集，稍后填充文件

```
用户操作：
1. 在文件夹中点击"新建" → "新建数据集"
2. 输入数据集名称（如"测试数据"）
3. 可选：直接拖拽上传文件
4. 点击"创建"完成
```

**场景二：基于零件版本创建数据集（推荐）**
> 设计师完成了零件设计，需要将CATIA文件上传到零件版本

```
用户操作：
1. 打开零件详情页
2. 点击"数据集"Tab
3. 点击"上传文件"或"添加数据集"
4. 选择/拖拽要上传的文件
5. 系统自动创建数据集并关联到当前零件版本
6. 上传完成后显示文件列表
```

**场景三：基于文档版本创建数据集**
> 设计师需要上传规格书PDF到文档版本

```
用户操作：
1. 打开文档详情页
2. 点击"数据集"Tab
3. 选择/拖拽PDF文件
4. 系统自动创建数据集并关联到当前文档版本
```

**数据模型：**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| dataset_id | VARCHAR(50) | 是 | 数据集唯一标识 |
| dataset_name | VARCHAR(200) | 是 | 数据集名称 |
| owner_id | VARCHAR(50) | 是 | 所属对象ID（零件/文档ID） |

| file_count | INT | 是 | 文件数量 |
| total_size | BIGINT | 是 | 总大小(Byte) |
| created_by | VARCHAR(50) | 是 | 创建人 |
| created_time | DATETIME | 是 | 创建时间 |
| updated_by | VARCHAR(50) | 是 | 最后修改人 |
| updated_time | DATETIME | 是 | 最后修改时间 |

**业务规则：**

| 规则ID | 规则内容 | 优先级 |

| FR-DS-001 | 数据集必须归属于某个文件夹 | P0 |
| FR-DS-002 | 数据集可选择关联零件版本或文档版本，也可不关联（独立数据集） | P0 |
| FR-DS-003 | 关联零件版本后，零件版本升版时数据集自动继承到新版本 | P0 |
| FR-DS-004 | 一个零件版本可有多个数据集 | P0 |
| FR-DS-005 | 数据集内文件变更不产生新版本，仅数据集版本+1 | P1 |
| FR-DS-006 | 数据集删除时，文件是否删除可配置（保留源文件/级联删除） | P1 |

### 3.4 详情面板功能分析
