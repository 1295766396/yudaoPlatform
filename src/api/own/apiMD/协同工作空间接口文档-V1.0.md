## 1. 通用说明

### 1.1 请求头

| Header | 值 | 说明 |
|--------|-----|------|
| Content-Type | application/json | POST/PUT 请求 |
| Authorization | Bearer {token} | 登录令牌 |

### 1.2 响应格式

所有接口统一返回 `CommonResult<T>` 格式：

```json
{
    "code": 0,
    "msg": "success",
    "data": {}
}
```

- `code = 0` 表示成功
- `code != 0` 表示失败，`msg` 中包含错误信息

### 1.3 分页参数

分页接口统一使用以下参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| pageNo | Integer | 否 | 1 | 页码，从 1 开始 |
| pageSize | Integer | 否 | 10 | 每页条数，最大 100 |

分页响应格式：

```json
{
    "code": 0,
    "msg": "success",
    "data": {
        "list": [],
        "total": 100
    }
}
```

## 2. 工作空间管理

### 2.1 创建工作空间

**接口：** `POST /admin-api/collaboration/workspace/create`

**权限：** 登录用户

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| workspaceName | String | 是 | 工作空间名称，2-50字符 |
| workspaceCode | String | 是 | 工作空间编码，2-32字符，英文+数字，字母开头 |
| workspaceType | String | 是 | 类型：TEAM-团队，PROJECT-项目 |
| permissionLevel | String | 是 | 权限级别：PUBLIC-公开，PROTECTED-受保护，PRIVATE-私有 |
| description | String | 否 | 描述，最多500字符 |

**请求示例：**

```json
{
    "workspaceName": "研发团队空间",
    "workspaceCode": "rd-team",
    "workspaceType": "TEAM",
    "permissionLevel": "PUBLIC",
    "description": "研发团队的协同工作空间"
}
```

**响应参数：**

```json
{
    "code": 0,
    "msg": "success",
    "data": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
}
```

**业务逻辑：**
- 创建人自动成为该空间的 Owner
- 系统自动生成 7 个基线角色
- 编码在租户内唯一

| 参数 | 类型 | 必填 | 说明 |

**业务规则：**
- 默认工作空间不允许删除

## 3. 成员管理

### 3.1 添加成员

**接口：** `POST /admin-api/collaboration/member/add`

**权限：** Owner 或 Administrator

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| workspaceUid | UUID | 是 | 工作空间UID |
| userIds | Long[] | 是 | 用户ID列表 |
| roleCode | String | 是 | 角色编码，默认 READER |

**请求示例：**

```json
{
    "workspaceUid": "a1b2c3d4-...",
    "userIds": [1, 2, 3],
    "roleCode": "READER"
}
```

**响应参数：**

```json
{
    "code": 0,
    "msg": "success",
    "data": {
        "successCount": 2,
        "skipCount": 1,
        "skipUserNames": ["张三"]
    }
}
```

**业务规则：**
- 已在空间中的用户会被跳过
- 添加成功后自动为新成员创建 Home 文件夹

---

### 3.2 移除成员

**接口：** `DELETE /admin-api/collaboration/member/remove`

**权限：** Owner 或 Administrator

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| workspaceUid | UUID | 是 | 工作空间UID |
| memberUid | UUID | 是 | 成员UID |

**响应：** `CommonResult<Boolean>`

**业务规则：**
- Administrator 不能移除 Owner
- 不能移除最后一个 Owner

---

### 3.3 变更成员角色

**接口：** `PUT /admin-api/collaboration/member/change-role`

**权限：** Owner 或 Administrator

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| workspaceUid | UUID | 是 | 工作空间UID |
| memberUid | UUID | 是 | 成员UID |
| newRoleCode | String | 是 | 新角色编码 |
| changeReason | String | 否 | 变更原因，最多256字符 |

**响应：** `CommonResult<Boolean>`

**业务规则：**
- Administrator 不能变更 Owner 的角色
- 变更后记录角色变更日志

---

## 5. 数据字典

### 5.1 工作空间类型 (workspaceType)

| 编码 | 名称 |
|------|------|
| TEAM | 团队 |
| PROJECT | 项目 |

### 5.2 权限级别 (permissionLevel)

| 编码 | 名称 |
|------|------|
| PUBLIC | 公开 |
| PROTECTED | 受保护 |
| PRIVATE | 私有 |

### 5.3 工作空间状态 (status)

| 编码 | 名称 |
|------|------|
| ACTIVE | 激活 |
| INACTIVE | 停用 |
| ARCHIVED | 归档 |

### 5.4 成员状态 (memberStatus)

| 编码 | 名称 |
|------|------|
| ACTIVE | 激活 |
| INVITED | 已邀请 |
| INACTIVE | 停用 |

### 5.5 角色编码 (roleCode)

| 编码 | 名称 | 层级 | 说明 |
|------|------|------|------|
| PUBLIC_READER | 公共读者 | 1 | 仅访问公开内容 |
| READER | 读者 | 2 | 访问全部内容 |
| CONTRIBUTOR | 贡献者 | 3 | 可创建评估类内容 |
| AUTHOR | 作者 | 4 | 可创建正式业务对象 |
| LEADER | 领导者 | 5 | 可管理公共资源 |
| ADMINISTRATOR | 管理员 | 6 | 空间管理权限 |
| OWNER | 所有者 | 7 | 空间完整控制权 |

### 5.6 角色类型 (roleType)

| 编码 | 名称 |
|------|------|
| BASELINE | 基线角色 |
| CUSTOM | 自定义角色 |

## 6. 错误码

### 6.1 工作空间相关

| 错误码 | 说明 |
|--------|------|
| 1003001000 | 工作空间不存在 |
| 1003001001 | 工作空间编码已存在 |
| 1003001002 | 该工作空间仍有成员，请先移除所有成员后再删除 |
| 1003001003 | 默认工作空间不允许删除 |
| 1003001004 | 该工作空间已归档，不允许创建新内容 |
| 1003001005 | 您无权访问此工作空间 |

### 6.2 成员相关

| 错误码 | 说明 |
|--------|------|
| 1003002000 | 成员不存在 |
| 1003002001 | 用户已在空间中 |
| 1003002002 | 不能移除工作空间的最后一位所有者 |
| 1003002003 | 权限不足：管理员不能操作所有者 |
| 1003002004 | 权限不足，无法执行此操作 |

### 6.3 角色相关

| 错误码 | 说明 |
|--------|------|
| 1003003000 | 角色不存在 |
| 1003003001 | 基线角色为系统内置，不可删除 |
| 1003003002 | 基线角色名称不可修改 |
