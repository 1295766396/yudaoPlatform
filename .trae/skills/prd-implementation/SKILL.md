# PRD Implementation - PRD实现规范

## 🎯 核心职责

确保每次PRD需求到Demo实现的完整过程遵循标准化流程，**绝不遗漏**PRD定义的功能点。

## 📋 标准执行流程（强制）

### 阶段1：实现前准备（必须优先完成）

在开始写代码之前，**必须先**完成以下步骤：

#### 1.1 完整阅读PRD文档
- [ ] 通读PRD全文
- [ ] 理解业务背景
- [ ] 标记所有功能点

#### 1.2 生成PRD功能提取表
```markdown
## PRD功能提取表

| 模块 | 功能点 | 优先级 | 是否已实现 | 备注 |
|------|--------|--------|------------|------|
| [模块名] | [功能描述] | [P0/P1/P2] | [是/否] | [补充说明] |
```

#### 1.3 创建详细实现计划
```markdown
## 功能实现计划

### 任务1：[模块名]
- **优先级**: [P0/P1/P2]
- **依赖**: [前置任务/无]
- **功能清单**:
  - [ ] 功能1描述
  - [ ] 功能2描述
  - [ ] 功能3描述
- **技术要点**:
  - 要点1
  - 要点2

### 任务2：[下一个模块]
...
```

#### 1.4 初始化功能对照表格
**必须使用以下格式**：
```markdown
## PRD vs Demo 功能对照表

| 模块 | 功能点 | PRD要求 | Demo实现 | 优先级 | 备注 |
|------|--------|---------|----------|--------|------|
| **模块名** | 功能描述 | ✅/❌ | ✅/❌ | P0/P1/P2 | 实现说明 |
```

### 阶段2：代码实现阶段

#### 2.1 按优先级顺序实现
- [ ] 优先实现P0功能
- [ ] 然后实现P1功能
- [ ] 最后实现P2功能（如有）

#### 2.2 即时标记对照
每完成一个功能点，**立即**在对照表格中标记：
```
原状态：| **模块** | 功能 | ✅ | ❌ | P1 | 待实现 |
新状态：| **模块** | 功能 | ✅ | ✅ | P1 | 已完成 |
```

#### 2.3 模块完成后检查
每完成一个完整模块，必须：
- [ ] 对照PRD检查所有功能点是否实现
- [ ] 确认没有遗漏
- [ ] 标记完成度

### 阶段3：完成后总结（必须）

所有功能实现后，**必须**完成：

#### 3.1 最终完整性检查
- [ ] P0功能100%实现
- [ ] P1功能全部实现或明确标记待做
- [ ] 功能对照表已完整更新

#### 3.2 更新功能对照表
必须包含以下统计信息：
```markdown
## Demo总体评估

| 维度 | 完成度 | 说明 |
|------|--------|------|
| P0功能完成度 | 100% | 说明 |
| P1功能完成度 | X% | 说明 |
| P2功能完成度 | Y% | 说明 |
| 整体界面风格 | ✅统一 | 说明 |
| 交互体验 | ✅良好 | 说明 |
| 与PRD契合度 | ✅高度契合 | 说明 |
```

#### 3.3 生成最终总结报告

## 🔍 功能对照表格标准（强制）

### 必须包含的列
| 列名 | 说明 | 必填 |
|------|------|------|
| 模块 | 功能所属模块 | ✅ |
| 功能点 | 具体功能描述 | ✅ |
| PRD要求 | PRD是否有此要求(✅/❌) | ✅ |
| Demo实现 | Demo是否已实现(✅/❌) | ✅ |
| 优先级 | P0/P1/P2 | ✅ |
| 备注 | 实现说明或待办事项 | ✅ |

### 实现状态标记标准
- ✅ = 已完全实现
- ⚠️ = 部分实现（需说明）
- ❌ = 未实现
- N/A = 不适用

## ⚠️ 遗漏预防机制

### 三重检查法
1. **逐条对照法** - 将PRD每个功能点复制到对照表格
2. **任务拆解法** - 将每个功能点拆分为实现任务
3. **完成验证法** - 每实现一个立即在表格标记完成

### 检查顺序建议
1. P0功能完整性检查
2. P1功能完整性检查
3. 功能对照文档更新
4. 整体流程演示验证

## 📝 输出文件要求

### 每次实现必须生成的文件
1. `功能实现计划.md` - 在实现前创建
2. `功能对照表.md` - 随实现持续更新
3. `实现总结报告.md` - 完成后生成

### 文件位置建议
建议放在项目的 `docs/` 或相应模块目录下

## 🚨 违规处理

每次发现以下情况，必须立即暂停并纠正：

1. **未创建实现计划就写代码** → 停止并创建计划
2. **功能对照表格未同步更新** → 立即更新对照
3. **PRD功能点遗漏** → 补充遗漏功能
4. **没有完整检查就结束** → 执行完整检查

## 💡 典型工作流程示例

### 完整PRD实现流程
```
用户需求：实现PRD XYZ功能

1. 调用此SKILL
2. 读取PRD文档
3. 生成功能提取表
4. 创建实现计划
5. 初始化对照表格
6. 按计划实现功能
7. 实时更新对照
8. 最终检查
9. 生成总结
10. 完成交付
```
