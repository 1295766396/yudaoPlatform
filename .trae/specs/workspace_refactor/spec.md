# 协同工作空间重构 - 产品需求文档

## 概述
- **摘要**：严格按照 PRD V1.2 重构协同工作空间模块，实现 7 个基线角色体系、完整的工作空间管理和成员管理功能
- **目的**：修正当前实现与产品文档的偏差，实现完整的业务功能
- **目标用户**：租户管理员、空间管理员、空间成员

## 目标
- 实现 7 个基线角色：Public Reader → Reader → Contributor → Author → Leader → Administrator → Owner
- 完善工作空间管理功能（CRUD）
- 实现完整的成员管理功能（添加、移除、变更角色）
- 实现角色体系层级可视化展示
- 更新数据结构，完全符合 PRD 的数据对象定义

## 非目标
- 不实现后端接口（仅前端静态页面和占位接口）
- 不实现工作空间切换（顶部导航功能，不在当前页面）
- 不实现自定义角色（仅基线角色）

## 背景与上下文
当前实现与产品文档的主要差异：
1. **角色体系**：当前是 4 个角色，需要改为 7 个基线角色
2. **数据结构**：缺少 workspace_code、workspace_type、permission_level、is_default 等关键字段
3. **成员管理**：缺少批量添加、角色变更等功能
4. **角色展示**：缺少角色层级结构图和权限展示

## 功能需求
- **FR-001**：更新角色体系为 7 个基线角色
- **FR-002**：更新工作空间数据结构（添加编码、类型、权限级别、默认标识等字段）
- **FR-003**：实现工作空间 CRUD 功能（符合 US-001 到 US-005）
- **FR-004**：实现成员管理功能（添加、移除、变更角色）
- **FR-005**：实现角色体系展示（层级结构图、权限详情）

## 非功能需求
- **NFR-001**：与现有模块（file、bom、appstore）风格保持一致
- **NFR-002**：使用 Element Plus 和 Icon 组件
- **NFR-003**：页面加载响应时间 < 2秒

## 约束
- **技术约束**：Vue3 + TypeScript + Element Plus
- **业务约束**：必须严格按照 PRD V1.2 和 UC V1.0 实现
- **依赖**：依赖项目已有的 Icon 组件

## 假设
- 后端接口暂时无法提供，使用 mock 数据
- 用户已理解"占位函数"的概念

## 验收标准

### AC-001：7个基线角色数据
- **给定**：打开协同工作空间页面
- **当**：查看角色体系
- **则**：显示 Public Reader → Reader → Contributor → Author → Leader → Administrator → Owner 7个角色
- **验证**：human-judgment

### AC-002：角色层级可视化
- **给定**：打开角色体系标签页
- **当**：查看角色
- **则**：以层级结构图展示角色继承关系
- **验证**：human-judgment

### AC-003：工作空间数据字段完整
- **给定**：查看工作空间列表/详情
- **当**：显示空间信息
- **则**：包含编码、类型、权限级别、默认标识等字段
- **验证**：human-judgment

### AC-004：成员管理功能完整
- **给定**：用户有管理权限
- **当**：操作成员管理
- **则**：可添加、移除、变更角色
- **验证**：human-judgment

### AC-005：编辑空间时编码不可修改
- **给定**：打开编辑对话框
- **当**：编辑空间信息
- **则**：编码字段为只读或隐藏
- **验证**：human-judgment
